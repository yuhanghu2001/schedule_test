## 2. `observe()` 输出字典

- `nodes`: `[M+1,10]` float32，边缘+云节点特征（每种资源占用率、内存/存储、队列、邻域链路压力、度、云标志、总算力）。
- `adjacency`: `[M+1,M+1]` float32，含自环，GAT邻居注意力的掩码；**云端只保留自环**，防止所有边缘节点通过云端形成两跳“超级连接”。物理边云链路仍保留在环境的 `self.adj`。
- `edges`: `[M+1,M+1,3]` float32，边速率/背景拥塞/传播时延。
- `task`: `[8]` float32，输入、输出、计算、截止、优先级、内存、类型、可卸载。
- `source`: 任务接入边缘节点的整数下标。
- `candidate_features`: `[K,10]`，动态K项候选动作的属性。
- `candidate_targets`: `[K]`，候选目标图节点下标。
- `candidate_paths`: `[K,M+1]`，路由中经过节点的归一化掩码，用于路径节点嵌入均值。
- `global_features`: `[9]` float32，包含任务/完成/时隙进度、累计时延能耗、已结束与当前时隙负载；仅使用决策前可知信息。

**重要**：边缘图没有直接将所有20个端侧节点加入GAT；端侧任务通过 `task` 和 `source` 输入策略网络。这是计算规模小的第一版设计。

## 3. 动作与约束落地

- 单动作编码记录 `destination`、`resource`、`path`、总时延/能耗、算力 `f`、固定传输项以及 Dinkelbach 得到的 `p_up`/上行速率；`step()` 的 `info` 额外暴露可行候选数与四项 reward 分量。
- `destination=-2` 表示拒绝、`-1` 表示端侧本地、`0..M-1` 表示区域边缘、`M` 表示云。
- `resource=0,1,2` 分别代表CPU/NPU/FPGA。
- `path=(s(i), ..., d(i))`，多跳动作由简单路径生成器产生；如果选择本地或接入边缘，路径为空或长度为1。
- `EdgeEnv._make_candidates()` 负责将可行性约束直接体现为候选动作集合。拒绝动作始终存在，是问题中 `y_i=0` 的合法决策。
- `EdgeEnv.step()` 修改时隙占用；任务一旦接收，`y_i=1`，否则0；虽然原型没有逐任务输出完整稀疏张量 `x,g,z`，每个动作信息可以唯一重建它们。

## 4. 当前实现的简化项（研发人员必须知悉）

| 项目 | 当前原型 | 正式研究版本 |
| --- | --- | --- |
| 功率优化 | Dinkelbach 求 `R(p)/(p+p_c)`，含最低速率约束 | 扩展多用户干扰与联合带宽分配 |
| 计算能力优化 | 带最低算力约束的 KKT active-set 并发分配 | 扩展跨时隙剩余工作量和迁移开销 |
| 无线接入 | 单接入节点，峰值速率抽样后反推信道增益，按 Shannon 公式计算 | 使用场景化信道增益、干扰与带宽调度 |
| 服务可用 | 规则生成服务支持 | 依据部署服务矩阵与模型文件状态 |
| 任务流 | 输入/计算量随机生成，deadline 由工作量参考时间乘松弛系数生成 | 根据场景生成器或真实trace配置 |
| 路由 | 枚举4跳以内简单路径，保留2条较短路径/目标 | 全部可行路径或经过论证的受控候选数 |
| 链路带宽 | 同时隙任务上传数据总量不超过容量 | 排队、实际吞吐、跨时隙转发和流量调度 |
| 下行回传 | 使用上传路径的逆向路径，计入每跳时延、能耗和反向容量 | 独立优化下行路由与发射功率 |
| 中继能耗 | 转发平均功耗×逐跳通信时间 | 细分发射/接收/空闲功耗与链路资源管理 |
| 端侧计算 | CPU/NPU/FPGA、内存、存储、队列与同槽并发 KKT | 扩展端侧电池状态和动态频率 |
| 负载公平 | 每时隙汇总端–边–云节点利用率方差 | 固定调度周期及业务类别分层统计 |
| 训练可视化 | 保存训练五指标曲线和固定验证集均值±标准差曲线 | 多种子置信区间和论文图表排版 |
| PPO实现 | GAE + shuffled mini-batch PPO-Clip，支持完整状态续训 | 并行环境和张量化变长图批处理 |
| 验证方式 | 可加 reward 不变量测试、固定种子贪心评估、best/last checkpoint、四方法聚合入口 | 实际执行论文预算并完成统计显著性分析 |

## 5. 必须重视的量纲

- `d_i/o_i` 是 MB，通信速率是 Mbps：单跳传输秒数 `8*d_i/C_mn`。
- `c_i` 是 GFLOP，`F_jq/f_ijq` 是 GFLOP/s：执行时间 `c_i/f_ijq` 秒。
- `slot_seconds` 是秒：单条链路在当前时隙可预留的数据量 `C_mn*slot_seconds/8` MB。
- `P` 是 W、`t` 是秒：能量 `E=P*t` J。
- 数据规模和带宽单位未统一之前，不应用任务完成率比较算法。

## 6. 工程边界

`AGENTS.md` 的“不写防御性代码”指避免冗余异常处理、重复校验和兜底分支；**物理约束的过滤必不可少**。为学术可复现而做的单次可行性回归测试也应当保留。
