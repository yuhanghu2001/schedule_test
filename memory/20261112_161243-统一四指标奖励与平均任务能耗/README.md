## 关键修改

```python
reward = (2.0 * task_completion_rate
          - 2.0 * average_completion_time
          - 1.0 * average_task_energy
          - 1.0 * load_imbalance)
```

完成率是最大化目标，其余三项是最小化目标，因此对应系数符号为 `+2:-2:-1:-1`。当尚无成功任务时，reward 中的平均时延和平均能耗记为 0；实验统计仍输出空值，不把 0 当作优良结果。
