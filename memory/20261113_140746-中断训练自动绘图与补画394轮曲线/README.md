# 中断训练自动绘图与补画394轮曲线

## 对话目标

让正式训练在用户按 `Ctrl+C` 手动中断时仍执行绘图和 checkpoint 收尾，并使用刚中断的正式训练 JSONL 补画曲线。

## 已完成事项

- `src/train.py` 捕获 `KeyboardInterrupt`，在 JSONL 文件关闭并刷新后统一执行绘图和 last checkpoint 保存。
- `src/plotting.py` 增加 `save_run_plots()`，直接从运行目录中的训练与评估 JSONL 重建图表。
- 若中断发生在首次固定评估之前，只根据已有训练数据生成训练图，不生成空评估图。
- 同步更新 README 和环境开发说明书，记录手动中断后的收尾行为。
- 使用 `results/20261113_134605/` 的 394 条训练记录和 15 条固定评估记录，补画 `training_metrics.png` 和 `evaluation_metrics.png`。

## 验证证据

- 25 项单元测试全部通过。
- 新增测试验证：只有训练 JSONL、评估 JSONL 为空时，仍会生成训练图且不生成空评估图。
- 补画的两张图均为 1920×1920 PNG；训练图覆盖第 1–394 轮，评估图覆盖第 25–375 轮。
- 已目视检查图表，五项训练曲线和五项固定评估曲线均正常显示。

## 未解决事项和实现边界

- 本次训练在新收尾逻辑加入前已终止，因此可从 JSONL 完整恢复图表，但无法从指标日志重建第 394 轮的模型参数；目录中保留的 `best_gat_ppo.pt` 不受影响。
- 新逻辑只使用已完整写入 JSONL 的 episode，不将正在执行且尚未完成的 episode 伪造为有效数据。

## 后续建议

- 后续中断后可用运行目录中的 `last_*_ppo.pt` 续训；续训仍应写入新的独立正式结果目录。
