# AI 工作记录规范

`memory/` 用于保存 Codex、Claude 等 AI 在本仓库中的完整对话与工作记录。

每次完整工作建立一个目录：

```text
memory/YYYYMMDD_HHMMSS-对话内容标题/
└── README.md
```

时间使用北京时间，标题应直接说明本次对话解决的主题。记录至少包含：

1. 对话目标。
2. 已完成事项。
3. 关键代码和文档修改。
4. 验证命令与结果证据。
5. 尚未解决的事项和实现边界。
6. 后续建议与常用运行命令。
