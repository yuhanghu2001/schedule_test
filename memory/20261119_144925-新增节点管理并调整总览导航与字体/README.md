# 新增节点管理并调整总览导航与字体

## 目标
落实用户四项要求：放大标题和时间，主导航替换为系统总览及节点管理，总览右侧显示全部节点并滚动，左侧资源名以颜色区分并删除前导图标。

## 完成事项与关键修改
- App.vue 主导航删除拓扑监控、任务调度、资源管理、算法评估；新增节点管理 /nodes，位于系统总览右侧。训练工作台、实验记录保留次级入口，原业务页面路由保留。
- 主标题在 1920/1600 桌面分别采用 38px/32px，时间为 20px/17px。
- OverviewDashboard 右侧移除分组切换，滚动显示全部 37 个节点（默认 12 边缘、1 云、24 终端）。计算节点显示资源利用率，端侧显示接入边缘与无线速率，不伪造本地算力。
- CPU/NPU/FPGA 删除前导图标，名称分别为蓝/绿/橙色。
- 新增 NodeManagement.vue：左侧类型筛选、搜索、分页和编辑列表，右侧真实邻接详情与属性编辑；支持恢复已保存配置和保存。
- 可编辑端侧实际无线速率，边缘/云端三类算力、内存、存储、队列容量，边缘五类服务；云端始终提供全部服务。端侧无本地计算、云端数量固定为 1。
- 保存到原 Pinia/localStorage 环境草稿，先请求环境预览成功再应用；总览默认用节点管理配置新建会话，训练工作台复用相同草稿。运行中会话不热修改。
- 先更新数学假设文档，再在 src/config.py 增加可选节点无线速率/容量元组，在环境初始化处接入；sim_service 仅补充配置元组转换。默认空元组保留原行为，无新场景 JSON。
- 训练工作台改变节点数量时同步调整显式配置数组，避免容量与节点数量不一致。
- 更新 README、系统设计文档，更新总览截图并新增节点管理截图；保留前一轮全部未提交改动。
