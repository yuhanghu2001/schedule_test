# 增加参考图风格拓扑监控页

## 目标

在系统总览右侧增加拓扑监控 tab，按用户新参考图实现独立大屏及背景，节点数量使用当前真实系统配置。

## 已完成

- 导航顺序为系统总览、拓扑监控、节点管理；`/topology` 指向独立页面。
- 原生 SVG/CSS 实现深蓝背景、点阵世界地图、透视网格、发光平台、云服务器、边缘服务器/无线接入、虚线分组区域及终端。保留现有全局标题和主题，不增加装饰性小图标。
- 默认完整显示 C0、E0–E11、U0–U23，四列三排边缘及一排全部终端。真实快照驱动数量、资源画像、速率、连线和路径。
- 复用原有环境草稿/API/节点详情面板，实现预览、策略/Checkpoint 选择、创建、单步、自动推演、暂停、重置；导航离开时清理本页会话。
- 实际页面截图保存到 docs/screenshots/topology-monitor-*.png；更新 README 与 docs/07。

新增 `frontend/src/views/TopologyMonitor.vue` 和 `frontend/src/components/NetworkMonitorScene.vue`；修改 `App.vue`、`router/index.js`、`styles/dashboard.css`。
