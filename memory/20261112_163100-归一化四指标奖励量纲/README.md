## 未解决事项

1. 当前 reward 是"截至当前任务的运行值"（绝对量），非每一步的增量贡献，逐步信号被 `1/t` 稀释，episode 累计奖励 ≠ 最终四指标。可改为 potential-based 增量 `r_t = Φ(s_{t+1}) − Φ(s_t)` 使累计等于最终目标。
2. `gamma=0.99` 对 600 步 episode 偏低（`γ^600≈0.24%`），最终指标几乎不被计入，建议上调到 0.995~0.999 或缩短 episode。
3. Critic 输入仍只有源节点嵌入 + 图均值 + 任务特征，缺少候选集规模/最优时延/时隙占用信息，优势估计方差偏大。
